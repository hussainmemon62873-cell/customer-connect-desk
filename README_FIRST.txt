CUSTOMER CONNECT DESK (CCD) — ROOT SEO / AI DISCOVERY PACK

IMPORTANT: This package is ONLY for the main Customer Connect Desk root website.
It does NOT contain or modify the separate Dynamic QR Platform.

COPY THESE THREE FILES TO THE ROOT OF YOUR EXISTING CCD REPOSITORY:
1. robots.txt
2. sitemap.xml
3. llms.txt

Do not put them inside dynamic-qr/.
Do not delete or replace your existing application files.
Do not upload this ZIP itself as a website file; extract it and copy the three files.

SITEMAP SCOPE:
The current root project has no dedicated public marketing/about page. The sitemap therefore includes only the public merchant registration page. It intentionally excludes admin.html, merchant.html, customer.html, shop.html and desk.html because these are private app interfaces or shop-specific/query-driven pages. The root customer sign-in page is not included as a search landing page.

ROBOTS.TXT:
Blocks private dashboard paths and the separate /dynamic-qr/ application from general crawler indexing. Robots.txt is crawler guidance, not access control. Private pages must remain protected by real authentication/authorization.

LLMS.TXT:
Provides a concise, privacy-safe description for AI systems. It deliberately excludes personal/customer records, PINs, tokens, spreadsheet data, and backend secrets.

AFTER DEPLOYMENT:
1. Open https://customer-connect-desk.pages.dev/robots.txt
2. Open https://customer-connect-desk.pages.dev/sitemap.xml
3. Open https://customer-connect-desk.pages.dev/llms.txt
4. Submit https://customer-connect-desk.pages.dev/sitemap.xml in Google Search Console and Bing Webmaster Tools.

IMPORTANT LIMITATION:
This pack adds discovery files only. It does not guarantee Google ranking, indexing, or AI citations. Google does not use the meta keywords tag as a ranking signal. A dedicated public CCD marketing page with substantial text about features, use cases, FAQs, contact details, and accurate structured data would improve search usefulness more than indexing a login form.
